# Доски квестов: API

Доска — холст ГМа: карточки записей, счётчиков, свободные подписи и кадры, между ними
нити. Всё под `gm_only`, префикс путей — `/api/campaigns/{campaign_id}`.

Ручек две породы. **Холст** (`boards.py`, тег `boards`) обслуживает браузер: координаты
в единицах холста, ссылки по uuid. **Агентский слой** (`boards_agent.py`, тег
`boards-agent`) обслуживает того, кто доску не видит: карточки зовутся ключами,
координаты ходят клетками сетки, сцена ставится одним запросом.

То же описание — перечни значений, схемы ответов и пример пакета — лежит в самой
спецификации: `/api/openapi.json` и `/api/docs`, тег `boards-agent`. Этот файл — краткая
памятка, спецификация первична.

## Агентский слой

### `GET /boards-dump`

Оглавление досок: `[{id, name, summary, cards}]`. С него начинают, когда доску назвали
по имени.

### `GET /boards/{board_id}/dump`

Снимок доски целиком — что где лежит и что с чем связано.

```json
{
  "board": {"id": "...", "name": "Дело о грузе", "summary": ""},
  "grid": {"col_px": 40.0, "row_px": 40.0, "note": "col/row — клетки сетки…"},
  "cards": [
    {"key": "gregor-varg", "kind": "entity", "name": "Грегор Варг",
     "col": 12, "row": 11, "cols": 13, "color": "amber",
     "entity": {"id": "…", "kind": "character", "summary": "…", "status": "active"},
     "notes": [{"tag": "улики", "text": "Врёт про манифест"}]},
    {"key": "pogonya", "kind": "clock", "name": "Погоня", "col": 16, "row": 14, "cols": 6,
     "clock": {"id": "…", "filled": 3, "segments": 6, "status": "active",
               "owner": "Синдикат «Борнико»", "outcome": ""}},
    {"key": "sluh", "kind": "text", "name": "Слух", "col": 18, "row": 4, "cols": 6,
     "text": "видели у дока", "font_size": 14}
  ],
  "edges": [{"from": "gregor-varg", "to": "sluh", "label": "видели вместе",
             "style": "thread", "color": "rust"}]
}
```

`key` — человекочитаемый ключ карточки в пределах доски (`gregor-varg`), выдаётся
автоматически из имени записи; карточкам, заведённым до появления ключей, он
проставляется при первом обращении. `col`/`row` — клетки: клетка равна 40 единицам
холста, `col` растёт вправо, `row` вниз. `cols` — ширина карточки в клетках.

### `POST /boards/{board_id}/batch`

Сцена одним запросом: карточки и нити между ними.

```json
{
  "cards": [
    {"key": "devi", "entity": "Деви Ясмин"},
    {"key": "pogonya", "clock": "Погоня", "col": 20, "row": 2,
     "notes": [{"tag": "почему", "text": "Синдикат поднял цену"}]},
    {"key": "zapiska", "kind": "text", "text": "груз ушёл через третий док", "font_size": 20},
    {"op": "update", "key": "gregor-varg", "notes": [{"tag": "улики", "text": "Ключ-карта"}]},
    {"op": "delete", "key": "staraya-zametka"}
  ],
  "edges": [
    {"from": "devi", "to": "gregor-varg", "label": "поставщик"},
    {"from": "zapiska", "to": "devi", "label": "со слов Кеса", "style": "dashed"},
    {"op": "delete", "from": "sluh", "to": "pogonya"}
  ]
}
```

Ответ: `{"board_id": "…", "cards": {"devi": "created", "gregor-varg": "updated",
"staraya-zametka": "missing"}, "edges": 3}`. В `cards` — исход по каждому ключу:
`created` | `updated` | `deleted` | `missing` (удаление ключа, которого на доске не было).
`edges` — сколько операций с нитями реально применено (создано, поправлено, удалено);
петля на одну карточку и удаление несуществующей нити не считаются.

Правила:

- `op` — `create` (по умолчанию; по занятому ключу правит существующую), `update`
  (карточки нет — 404), `delete`. У нитей — `create` или `delete`.
- `entity` и `clock` принимают **имя** записи или счётчика кампании (регистр не важен;
  подходит и uuid). Неоднозначное имя — 400 с перечнем кандидатов и их айди.
- `kind` — `entity` | `clock` | `text` | `image` | `sketch` | `name`; при заданных
  `entity`/`clock` выставляется сам. `sketch` — поле для рисования от руки (в снимке —
  число росчерков и подписи), `name` — статист: имя и описание, в базу кампании не идёт.
- Любая ошибка откатывает весь пакет: 400 — неоднозначное имя, карточка записи/счётчика
  без цели, нить к несуществующему ключу; 404 — `update` по отсутствующему ключу,
  запись или счётчик не найдены.
- Без `col`/`row` карточка ложится на первое свободное место сверху вниз, с клеткой
  воздуха между соседями. Высота считается по роду карточки (точная известна только
  браузеру: её задаёт текст).
- `notes` заменяют список записок целиком; каждой выдаётся `id`, если его нет.
- Нити между одной парой не плодятся: повтор правит подпись, цвет и стиль
  (`thread` | `dashed` | `arrow`).

### Записки

Записки живут на карточке доски (`notes`) и одновременно прирастают к самой записи или
счётчику — одним блоком `ContentBlock` под именем доски (`Доска: Дело о грузе`),
сгруппированным по тегам. Пустой список — блок убирается. В интерфейсе они видны в
полном окне записи и в окне счётчика, читать их можно и через
`GET /blocks/{entity|clock}/{id}`.

## Холст (для браузера)

| Метод | Путь | Что делает |
|---|---|---|
| `GET` | `/boards` | список досок с числом карточек |
| `POST` `PATCH` `DELETE` | `/boards`, `/boards/{id}` | завести, переименовать, удалить |
| `GET` | `/boards/{id}/cards` | карточки с разрешёнными записями и счётчиками |
| `POST` `PATCH` `DELETE` | `/board-cards`, `/board-cards/{id}` | карточка целиком |
| `GET` | `/boards/{id}/edges` | нити доски |
| `POST` `PATCH` `DELETE` | `/board-edges`, `/board-edges/{id}` | нить |

Координаты карточки — `x`, `y`, ширина `w` в единицах холста; `z` — порядок наложения;
`font_size` текстовой карточки — 10…240.
