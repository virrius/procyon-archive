# Сборка под flux1-krea-dev (GGUF)

Снимок промпт-слоя на 9 августа 2026, доведённый под flux ночным прогоном
(`reports/night_flux.html`). Пайплайн вернулся на SDXL (zavychromaxl_v80), потому
что стол выбрал её живописную дисциплину как основную; здесь лежит рабочая
flux-сборка целиком. Вернуться — скопировать оба файла обратно в `backend/app`
(`images_router.py` → `routers/images.py`).

## Что в снимке

- `image_prompts.py` — инструкции для Квена (проза, три головы), словари регистров,
  закон сеттинга, подмены земных слов (`EARTH_WORDS`), манеры фразами, рамки кадра.
- `images_router.py` — схема слотов (brief_subject / brief_scene / no_people),
  сборка промпта прозой, пустой негатив.

## Настройки рисующей стороны

```
PA_CHECKPOINT=flux1-krea-dev-Q5_K_M.gguf
PA_STEPS=28
PA_CFG=2.5          # guidance, не cfg — дистилляция
PA_SAMPLERS=dpmpp_2m
```
Планировщик beta.

## Чем эта сборка держится

Проза, а не теги: у flux языковой энкодер T5 с окном 512 токенов. Веса в скобках
и негатив не работают (дистилляция), поэтому вся дисциплина — словами: рамка кадра
первой фразой и повтором в хвосте, материал места в первых словах слота, подмена
земных слов кодом (`tunic` → мундир с погонами, «nose» → самолёт).

Сильная сторона: следование описанию — 24/40 попаданий на бенче сеттинга против
1–4 пунктов из 8 у SDXL-сборки. Манеры у flux всего две (фото и «крашеная
иллюстрация»), все печатные техники сводятся к комиксу.

Слабая: живописная подача беднее SDXL, и негативом кадр не подрулить.
